# Rosinha Campos Buquês Site

Site estático para o negócio de buquês de casamento Rosinha Campos Buquês localizado em Franca/SP.

## Sobre o Site

Site desenvolvido com HTML, CSS e JavaScript nativo (sem frameworks). Página única com todas as funcionalidades implementadas diretamente.

## Estrutura do Site

- `index.html` - Página principal do site
- `hero-image.jpeg` - Imagem do herói (2K)
- `como-funciona-bg.png` - Imagem de fundo da seção "Como funciona"
- `sobre-buque.jpg` - Imagem da seção "Sobre a Rosinha"
- `og-image.jpg` - Imagem para compartilhamento social
- `robots.txt` - Instruções para rastreadores
- `sitemap.xml` - Mapa do site
- `llms.txt` - Informações para sistemas de IA

## Funcionalidades

- **Catálogo 3D** - Carrossel de fotos com efeito coverflow
- **Lightbox** - Visualização ampliada das fotos
- **Responsivo** - Design adaptado para mobile e desktop
- **SEO otimizado** - Schema.org, Open Graph, Twitter Cards
- **Performance** - Carregamento rápido sem dependências externas

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox, Transforms)
- JavaScript nativo (ES6+)
- No build tools required

## Deployment

O site pode ser publicado em qualquer serviço de hospedagem estática como Vercel, Netlify, GitHub Pages, etc.
